# 健康年表

由 Apple Health Web 迁移而来的原生 iPhone 工程。使用 SwiftUI、Swift Charts 和 Swift 数据处理，界面、导入、计算和图表均在设备上运行。最低部署版本为 iOS 17。

## 在 iPhone 上使用

1. 在 Mac 上打开 HealthTimeline.xcodeproj。
2. 在 HealthTimeline 目标的 Signing & Capabilities 里选自己的 Team。选择已连接并信任的 iPhone，点 Run。
3. 在 iPhone 的「健康」里点个人资料，再点「导出所有健康数据」。将 ZIP 存到「文件」。
4. 打开「健康年表」，选择健康导出文件。点「耳朵」，再选择自己的 AirPods，可查看时长、日趋势和分时段音量。

## 报告和统计方式

| 报告 | 内容 |
| --- | --- |
| 概览 | 日期范围、关键统计、24 小时心率与活动能量、睡眠趋势、体重等原始记录 |
| 耳朵 | 耳机名筛选，累计和每日聆听时长，按时长平均的音量、较高音量占比 |
| 心脏 | 心率、血氧、心率变异性、呼吸频率、静息心率、周分布、直方图及日历 |
| 睡眠 | 每夜时长、阶段结构、入睡和起床区间，以及睡眠目标、手腕温度等记录 |
| 活动 | 步数日历，距离、锻炼、活动圆环、训练分类、时段和训练明细 |
| 能量 | 活动和静息能量，身体负荷，站立小时，按月爬楼 |
| 移动 | 步速、步长、双支撑、不对称、上下楼、稳定性和六分钟步行距离 |
| 设备 | 设备名称、写入来源、导出资料及记录类型统计 |

快速日期范围以导出记录的最后一天为准。耳机时长按耳机名称归组，合并同一设备重叠的时间，并按记录时间拆分跨午夜区间。报告只计算 Apple 健康实际写入的记录。

导入接受 Apple「健康」的 ZIP 和已解压的 XML。ZIP 流式解压到应用临时目录，Swift 的 XML 解析器逐条读取，导入结束会清理临时文件。报告保存在当前会话内存中。

参考项目为 [tf-pogo/apple-health-web](https://github.com/tf-pogo/apple-health-web)，原项目的 MIT 许可随工程提供。
